# Calorie & Workout App

Учебный проект: приложение на C# WPF + MS SQL Server для расчёта суточной нормы калорий и составления программ тренировок.

**Статус:** в разработке. Первый спринт: каркас UI готов.

## Стек
- C#
- WPF (XAML)
- MS SQL Server
- Entity Framework Core

## Что уже есть
- Главное окно `MainWindow` с `TabControl` на три вкладки
- Заготовки разделов: **Профиль**, **Упражнения**, **Программа**
- Ветки под каждую роль (`feature/*`)
